# プライバシーポリシー（Codex Blanche Web）

**日本語** | [English](PRIVACY_POLICY.en.md)

**最終更新日: 2026年5月7日**（著作権者名義を Belleval office に統一）

本プライバシーポリシー（以下「本ポリシー」）は、Web アプリケーション「Codex Blanche」（以下「本アプリ」）における個人情報および関連データの取り扱いについて説明するものです。本アプリを利用することにより、ユーザーは本ポリシーに同意したものとみなされます。

## 1. Belleval office（著作権者）

本アプリのソースコードの著作権者名義は **Belleval office** です。配布・開発のホスティングは [Tamari-log/Codex-Blanche](https://github.com/Tamari-log/Codex-Blanche) を通じて行われる場合があります。例: GitHub Pages（https://tamari-log.github.io/Codex-Blanche/）。別の主体がミラー配布している場合は、当該配布者のプライバシー情報もあわせてご確認ください。

## 2. 本アプリが扱うデータの概要

本アプリは、チャット履歴、設定、API キー（ユーザーが入力した場合）、プリセット、オプションの Google アカウント連携に関するトークン等を **主にユーザーのブラウザ内**（`localStorage` / `sessionStorage` 等）で処理します。Belleval office が、本アプリ単体を通じて **会話内容を自社サーバーへ集約して保存する設計ではありません**（下記の第三者 AI サービス送信および任意の Google Drive は除く）。

## 3. 第三者の AI サービス（Gemini / OpenAI 等）

1. ユーザーがメッセージを送信すると、選択した AI プロバイダの API へ **会話内容、添付から抽出したテキスト等**が送信される場合があります。  
2. これらのデータの取り扱いは、**各プロバイダのプライバシーポリシーおよび利用規約**に従います。  
3. API キーは設定に応じて `sessionStorage` または `localStorage` に保持され、AI プロバイダへの認証に使用されます。Belleval office がキーを受け取ることは通常ありません。

## 4. Google ドライブ連携（任意）

1. ユーザーが Drive 同期を利用した場合、Google の認証および Google Drive API を利用して、バックアップ JSON 等のファイルを読み書きする場合があります。  
2. Google の [プライバシーに関する方針](https://policies.google.com/privacy) 等が適用されます。

## 5. ネットワークとログ

1. 本アプリは、AI API および Drive API 等への通信のためにインターネット接続を使用します。  
2. ブラウザの開発者ツールや拡張機能により、ネットワーク上のリクエストが記録される場合があります。

## 6. 画像・文書などの添付

ユーザーが選択したファイルは、主にブラウザ内で処理され、AI に送信するために加工される場合があります。**機微な個人情報や業務秘密**を含むコンテンツを送信する際は、各 AI プロバイダのデータ取り扱いを十分に確認してください。

## 7. 子どもの利用

本アプリは、子どもを対象としたサービスを意図していません。保護者の監督のもとでご利用ください。地域の法令で年齢制限がある場合は、それに従ってください。

## 8. セキュリティ

ブラウザ内ストレージやインターネット通信は **完全に安全であるとは限りません**。端末の共有やマルウェア対策、API キーの管理はユーザー自身の責任が重要です。

## 9. 本ポリシーの変更

Belleval office は本ポリシーを更新することがあります。更新後の内容は、本リポジトリ上の本ファイルの改訂により告知します。継続利用により、変更後のポリシーに同意したものとみなす場合があります。
