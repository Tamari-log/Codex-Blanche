プライバシーポリシー（Codex Blanche Web）

最終更新日: 2026年5月7日

1. Belleval office（著作権者）

本アプリのソースコードの著作権者名義はBelleval officeです。ホスティング例: Tamari-log/Codex-Blanche、GitHub Pages。

2. 処理するデータ

チャット、設定、API キー、プリセット、任意の Google 連携トークン等を主にブラウザ内（localStorage / sessionStorage）で扱います。Belleval office が本アプリ単体で会話を自社サーバーに集約保存する設計ではありません（AI API 送信および任意の Google Drive を除く）。

3. 外部送信（AI API）

メッセージや添付から得た内容が、選択したプロバイダ（Gemini / OpenAI 等）へ送信されます。各社のポリシーが適用されます。

4. API キー

既定は sessionStorage。「保存」オプションで localStorage に保持する場合があります。Belleval office がキーを受け取ることは通常ありません。

5. Google Drive（任意）

同期利用時は Google の認証・Drive API を利用します。Google のプライバシーポリシー等が適用されます。

6. セキュリティ・お問い合わせ

ブラウザ保管と通信は完全には安全ではありません。ご質問は Issues へ。Belleval office は本ポリシーをリポジトリ上で更新する場合があります。

Privacy Policy (Codex Blanche Web)

Last updated: May 7, 2026

1. Belleval office (copyright holder)

Belleval office is the copyright holder. Hosting may be via Tamari-log/Codex-Blanche and GitHub Pages.

2. Data processed

Chats, settings, API keys, presets, optional Google tokens—primarily in-browser (localStorage / sessionStorage). Not designed to upload chats to an operator-controlled backend (except calls to AI APIs and optional Drive).

3. External transmission

Content may be sent to Gemini / OpenAI per your selection; each provider’s policy applies.

4. API keys

Default sessionStorage; optional localStorage when “remember” is enabled. Belleval office typically does not receive your keys.

5. Google Drive (optional)

Uses Google sign-in and Drive API; see Google’s privacy policy.

6. Security / contact

No storage is perfectly secure. Contact: Issues. Belleval office may update this policy in the repository.
